START HERE

讓每個按鍵，都跟上你正在做的事。

保持本程式開啟，連接 Speed Editor，開啟「自動切換」。切到目標程式後，按鍵與旋鈕會套用對應配置，浮動面板也會一起更新。

第一次使用

  1. 連接控制器，確認下方裝置狀態。
  2. 在「應用程式」確認掃描完成。認得的軟體使用專屬範本，其餘使用可自訂的通用配置。
  3. 開啟 YouTube、PotPlayer 或文書程式，查看浮動面板目前的功能。
  4. 按硬體按鍵或轉旋鈕。回到編輯器時，保留你正在編輯的配置。

本機功能不需要登入。登入只用於雲端設定檔。未偵測到裝置時，先確認 USB／藍牙連線與其他程式是否占用控制器。

MOUSE CONTROL

每個程式，都用同一組滑鼠鍵。

六個滑鼠鍵集中在同一區，切換程式或配置後位置也相同。直接按實體按鍵即可使用，無須逐一設定範本。

要做什麼固定操作
左右移動按住 SLIP SRC＋轉旋鈕。
上下移動按住 SLIP DEST＋轉旋鈕。
左鍵選取按 CUT。
右鍵選單按 DIS。
雙擊按 SMTH CUT。
拖曳、選文字或框選按住 TRANS DUR＋SLIP SRC 或 SLIP DEST，再轉旋鈕。

放開方向鍵，旋鈕恢復目前程式的用途。拖曳時可放開方向鍵再換另一方向；放開 TRANS DUR 才結束拖曳。

移得更細，捲得更慢

預設每次移動 2 像素。啟用輕柔加速時，連續快速轉動才逐漸增加至 4 像素；停頓、反轉或換方向後恢復細步移動，放開後不會繼續滑動。捲動量預設為 8。

到「通用操作」調整滑鼠移動距離、捲動量及加速。設定會套用所有程式；想要最精細的操作，可將移動距離設為 1 並關閉加速。

固定通用操作

預設按住 LIVE OWR 進入通用操作：直接轉旋鈕可移動左右，加按 SLIP DEST 可移動上下。按 JOG 後轉旋鈕可捲動頁面；SHTL、SCRL 分別切回左右、上下。放開 LIVE OWR 就回到目前程式。

同組按鍵通用功能
CAM 1／2／3複製／貼上／剪下
CAM 4／5／6復原／重做／全選
CAM 7／8／9尋找／儲存／切換視窗

通用功能要按住通用鍵；上方六個固定滑鼠鍵隨時可直接使用。浮動面板會顯示目前生效的功能，點擊圖中的按鍵只會查看提示。

FLOATING GUIDE

配置留在眼前，工作留在原處。

Ctrl＋Alt＋F12 或主畫面的「浮動按鍵面板」可顯示／隱藏。拖曳標題移動，拖曳右下角改變大小。

大小與文字

完整模式在寬版、窄版與直向視窗都保留實體鍵盤排列，按鍵位置不會因視窗形狀改變。勾選「精簡」只顯示 12 個常用控制。

空間不足時，會先移除 SMART INSRT 等原按鍵文字，將空間讓給目前功能。滑鼠停留仍可看到完整功能與硬體名稱。

半透明與穿透

底部不透明度控制面板整體透明程度。勾選浮動面板的「穿透」，點擊就會傳到背後視窗。要重新移動、縮放或操作面板，到主視窗底部取消「面板穿透」即可；「應用程式 → 滑鼠穿透」也能調整同一設定。

面板移出螢幕時按「移回目前螢幕」。按住通用鍵或切換其他功能頁時，面板會跟著顯示對應配置。

面板是硬體功能提示；點擊圖中的按鍵不會執行硬體動作。

MAKE IT YOURS

選一個看得舒服的顏色。

在「外觀」選霧藍、薄荷、薰衣草、玫瑰、琥珀或冰川，也可以按「自訂顏色…」選色。主視窗、按鍵、選單與浮動面板會一起更新。

  • 亮色介面：切換深色／亮色，文字會跟著調整。
  • 霧面濃度：調整表面的遮蔽程度。放開滑桿即儲存。
  • Windows 毛玻璃：支援的 Windows 11 使用系統 Acrylic 背景。舊版 Windows 或系統效果不可用時，使用漸層霧面底色。

顏色會儲存，重新開啟或搬移設定後仍會保留。浮動面板的不透明度可另外調整。

YOUR MAPPINGS

先選程式，再設定按鍵。

  1. 「應用程式」搜尋目標軟體。
  2. 按「在範本中編輯按鍵…」。
  3. 選硬體鍵，從「帶入預設」選功能並帶入，或自行設定動作。
  4. 按「儲存」或 Ctrl＋S。變更會立刻寫入目前設定。

可設定快捷鍵、按住修飾鍵、程式切換、OBS、配置層、旋鈕及滑鼠操作。原有複製、匯入／匯出與手動配置層仍可使用。

「選擇顯示的程式」只整理清單，不會刪掉設定或停用辨識。掃描找不到的可攜程式，可按「加入可攜程式…」。

快捷鍵依各軟體的版本、目前面板及自訂鍵位而異；若你改過軟體快捷鍵，請在此改成一致。

Shorts 的 IN／OUT 切換上一則／下一則；旋鈕進度約每步 5 秒。Shorts 使用系統音量，避免上下鍵誤換片，目前不提供一般影片的速度與百分比跳轉快捷鍵。

PotPlayer 有 41 項預設，包含逐格、字幕、A–B 循環、播放清單與開檔。YouTube 控制前先選取播放器，文字輸入中不會把控制指令打進欄位。

OBS STUDIO

讓場景與音訊伸手可及。

  1. 在 OBS 開啟 WebSocket 伺服器。
  2. 本程式「設定 → OBS WebSocket」填入相同主機、連接埠與密碼，再按「連線」。
  3. 切到 OBS，使用對應配置。CAM1～9 依 OBS 場景清單切換。

SOURCE、SHTL、SCRL 分別切換旋鈕控制場景、麥克風音量、桌面音訊音量。43 項預設也包含錄影暫停、重播緩衝、工作室模式、轉場、虛擬攝影機與媒體操作。

來源與濾鏡需要先在「OBS 進階控制」指定名稱；可按「讀取 OBS 場景與來源」取得清單。回放緩衝要先在 OBS 啟用。

媒體操作與其他功能

滑鼠區維持所有程式相同的六個按鍵。原本佔用這些位置的 OBS 功能保留在「程式其他功能」頁：按住通用鍵（預設 LIVE OWR），再按 ESC。保持通用鍵按住，使用左上方相鄰的六個按鍵：

位置左中右
上排SMART INSRT：上一個媒體APPND：播放／暫停RIPL OWR：下一個媒體
下排CLOSE UP：重新播放PLACE ON TOP：停止媒體SRC OWR：切換濾鏡

再次按 ESC 回到通用功能，放開通用鍵回到 OBS 專用配置。浮動面板會顯示目前這一頁的功能名稱；自訂配置有更多其他功能時，ESC 會依序切換各頁。

KEEP YOUR SETUP

本機能用，雲端可存。

登入前先到「設定 → 匯出 JSON…」保留按鍵配置。按程式內的「登入」，在瀏覽器完成帳號登入；出現「Signed in to Unbound」即可回到程式。

若登入後停在 Unbound API 首頁，可回到程式登入時開啟的裝置頁完成連接。Clerk 的開發者後台不需建立應用程式。

功能作用
儲存目前設定…把配置層保存為有名稱的雲端設定檔。
載入所選設定檔取代目前所有配置層。
立即同步下載雲端配置；登入成功也會自動執行。

立即同步不是上傳備份。先匯出想保留的配置，再下載雲端內容。

搬到另一台電腦

關閉程式，把 EXE 與 config.json 一起放到可寫入資料夾；不需要安裝 Python 或攜帶 _internal。只帶 EXE 會建立新配置。帳號登入資訊由該電腦保存，換電腦需要重新登入。

QUICK FIXES

先確認現在生效的配置。

滑鼠不動

確認硬體裝置已連接。按住 SLIP SRC 再轉旋鈕移動左右；按住 SLIP DEST 再轉旋鈕移動上下。這組位置適用所有程式。

捲動太快

到「通用操作」降低捲動量，所有程式會一起變慢。滑鼠太快則降低移動距離，或關閉輕柔加速；預設為 2 像素、捲動量 8。

面板擋住視窗

勾選浮動面板的「穿透」，或按 Ctrl＋Alt＋F12 隱藏。要操作面板時，回主視窗底部取消「面板穿透」。快捷鍵被占用時，使用主畫面的「浮動按鍵面板」。

按鍵無反應

確認裝置已連接、目標程式在前景、按鍵有配置。原軟體的自訂快捷鍵與權限差異可能影響控制。雲端登入不會解決硬體連線問題。

儲存失敗或程式意外關閉

將程式放在可寫入資料夾，保留 config.json 與備份。問題發生時可查看同資料夾的 SpeedEditorCustomizer-errors.log；分享前移除私人資訊。
